# Design System

## Product Character

- Trustworthy
- Professional
- Calm
- Clear

## Visual Direction

- Use a consistent visual hierarchy.
- Prioritize readability and usability.
- Avoid unnecessary gradients, shadows, cards, and animations.
- Reuse existing design tokens and components.
- Keep financial information clear and easy to scan.

## Required Interface States

- Default
- Loading
- Empty
- Error
- Disabled
- Success

## Responsive Design

- Support desktop and mobile layouts.
- Avoid fixed widths that break on smaller screens.
- Tables must have an appropriate mobile presentation.
- Forms must remain readable on narrow screens.

## Accessibility

- Use semantic HTML.
- Provide visible labels for form fields.
- Support keyboard navigation.
- Maintain sufficient contrast.
- Do not communicate status using color alone.
